Using `00-product-contract.md`, complete the public-facing project materials.

Expand `README.md` into operator-grade documentation covering every documentation requirement in the contract. Include a concise permissions rationale and privacy statement. Explain how to change the hosted URL, publish GitHub Pages, keep active/web CSV copies synchronized, run merge/dry-run/tests, interpret conflict exits, and validate the extension manually.

Check link paths, viewport behavior, keyboard focus, contrast, reduced-motion behavior if animation exists, and missing-network behavior. Report results and stop.
