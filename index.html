Why we built it

Built from a problem we felt ourselves.

We were building our own passion project when we realized how close this was to something we needed every day: a way to engage faster and more effectively. So we made it useful for everyone watching a busy feed.

Focused by design

Less hunting. More recognizing.

VIP Coin turns a crowded page into a readable watchlist without sending your personal terms anywhere.

01 / WATCH

Spot VIP profiles

Known names, handles, and profile links receive a clear yellow highlight and VIP outline.

02 / CUSTOMIZE

Add your own signals

Track any name, phrase, or word. Your personal matches appear in blue and stay in your browser.

03 / KEEP UP

Works as the page moves

Newly loaded content is scanned automatically, so matches appear without a manual page refresh.

Get started

From download to detection.

  1. Download and unzipGet the project from GitHub and keep the folder somewhere convenient.
  2. Open Chrome extensionsVisit chrome://extensions and turn on Developer mode.
  3. Load the folderChoose “Load unpacked,” select the project folder, turn on the extension’s toggle, then refresh the website you want to scan.
  4. Make it yoursOpen VIP Coin to pause highlighting or add exact, contains, starts-with, ends-with, and regex keyword rules.
